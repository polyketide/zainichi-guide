## 読み方

- **全部やらなくてよい**：いまの自分に関係する一つ二つを選んでください。
- **条件で探す**：リポジトリの直下で `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/?lang=ja` を開きます。キーワード、節、得られるもの、コスパの段階で絞り込めます。
- **一行だけ読む**：各項目の「ひとことで」は、「根拠」欄にある内容だけを日常の言葉にしたものです。
- **「原文を確認していません」とある箇所**：逐語的に確認できる公的な原文が見つからなかったので、結論を書いていないという意味です。「問題がない」という意味ではありません。
- **個別の事案**：この本は一般的な扱いだけを書いています。自分の申請が通るか、税がいくらかは、入管、税務署、年金事務所、市区町村、または行政書士・税理士・弁護士に確認してください。

各項目の欄：コスト／ひとことで／根拠／証拠レベル／出典／備考。見出しの下の `<!-- 成本标签: … -->` は検索ページ用の機械可読タグで、正本と同じ中国語のまま残しています（钱＝お金、时间＝時間、毅力＝根気、收益＝効果の大きさ、口径＝得られるものの種類）。

## 証拠レベル

| レベル | 意味 |
| --- | --- |
| A | 具体的な数字がある、または法令・公的文書の原文を引用している |
| B | 根拠はあるが数量化しにくい、または出典が一つだけ |
| C | 筆者の経験や一般に言われていることで、確認できる原文がない |

現在 69 項目はすべて A です。原文を引用できる事柄だけを先に書いたためで、礼金・更新料・保証会社など、裁判例や実務に依る内容はまだ書いていません。

A は「その文が原文にある」ことだけを示します。法律に権利が書いてあっても、申し出ればすぐ実現するとは限りません。

**時点**：金額と期限には適用日または年度を書いています。全体は 2026-10-05 時点です。使う前に出典欄の原ページを確認してください。
