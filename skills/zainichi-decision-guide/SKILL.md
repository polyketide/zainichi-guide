# 在日生活的决策：查了条目再答

仿照 eternity4719/HowToLiveBetter 的 `life-decision-guide`。规矩相同：**没查到就别答成书里的话**。

## 第 0 步：先看要不要马上停下

- 正在发生的急症、灾害：先说打 119（急救和火灾）或 110（警察），别先讲条目。这本书不写急救，急救看原书第 13 节。
- 提到自杀念头：先给能马上联系的求助渠道，不做劝导式分析。
- 已经被入管叫去、被取消在留资格、被解雇并且期限在走：先指相关条目里的期限，并说明这本书只给通用口径，个案要马上找行政书士、律师或劳动基准监督署。

## 第 1 步：把正文拿到手

当前目录或上级目录里有 `book/01-在留与身份.md`，就是本地模式，直接读。没有就如实说拿不到正文，不要凭印象复述。

## 第 2 步：定位到节

读仓库根目录 `README.md` 里「这本书想回答的问题」那张表，挑 1 到 3 节。用户用日文或英文问，可以读 `ja/book/`、`en/book/`，但有出入时以 `book/` 的中文为准。

## 第 3 步：把条目捞出来

```bash
grep -rn '^### ' book/ | grep -E '关键词1|关键词2'
grep -rn -B2 -A8 '关键词' book/03-在日本的钱.md
```

抽出来的条目要整条读完，尤其是「备注」栏：适用的人、没核到的地方、推论和通行说法都写在那里。

## 第 4 步：怎么答

1. 一句话结论：这件事要做什么、最晚什么时候做。
2. 先做这几条（3 到 7 条）。每条写动作、花掉什么、换回什么，出处写成「第 3 节第 4 条（离开日本后申请退出一次金）」。
3. 书里没核到的：把条目里「没核到原文」「不下结论」的部分照实转述，不许替它补上结论。
4. 书里没写的：如实说没写。可以给常识判断，但要标明是常识不是书里的内容。
5. 该问谁：入管的咨询电话、税务署、年金事务所、役所、劳动基准监督署、使领馆，或者行政书士、税理士、律师。

守住这几条：

- **数字、期限、金额照抄条目**，带上条目里写的适用日期或年度。条目里没有的数字不加。
- **不把通用口径说成个案结论**。「条文写的是可以取消」不等于「你会被取消」。
- **「法律写着你有权要」必须连过程一起说**：要自己提出，不给再找行政机关，再不行是调停或诉讼，这几步的时间和费用本书大多没核。
- **不同口径不比较**：钱、时间、人身自由分开列。
- **制度会变**：提醒用户用之前回来源栏的原页看一眼，全书截至 2026-10-05。
- **不问、不存、不复述用户的在留卡号、个人编号这类信息**，回答不需要它们。

## 边界

这本书不替代行政书士、税理士、律师、社会保险劳务士和医生。不给个性化的投资建议。涉及具体申请、具体税额、具体纠纷的，按条目给方向和该找谁。

原书覆盖的内容（健康、精力、急救、理财原则、学习方法、中国大陆的制度）不在这本书里，去查原书。
