# 在日华人版 高性价比人生指南

讲留学生从语言学校到考大学、考大学院、读专门学校各有什么硬条件，在日本怎么保住在留资格，上班和离职时法律给了什么，年金、健保和税怎么交、能拿回什么。讲人在日本时中国那边还剩哪些义务，怎么租房，父母在国内的事怎么远程办，回国那一步按什么顺序了结。<br>
93 条建议，每条写明花掉什么、换回什么，依据是哪一条法令或官方文件的原文。

不用全做：这是按性价比排好的备选单，不是任务清单。

**这是初稿。** 正文里写着「没核到原文」的地方还没有核实。本书不是法律、税务或移民方面的专业意见，个案请问主管机关或专业人士。

## 怎么读

- **不用全做**：挑和自己眼下有关的一两条。剩下的放着，需要时回来查。
- **想按条件挑**：打开[在线检索页](https://polyketide.github.io/zainichi-guide/)。想在自己电脑上跑，在本目录运行 `python3 -m http.server 8000`，浏览器开 `http://localhost:8000/`。检索页可以按关键词、章节、换回什么、性价比档筛，也可以只看不花钱、花时间少、不靠毅力的条目，可以切换中文、日文、英文。页面内容直接取自正文，正文一改页面跟着改。
- **想按顺序读**：每节内的条目按性价比从高到低排，从每节前几条看起。
- **只看一行**：每条都有一行「说人话」，只用「收益」栏已有的内容，不添新数字。看这一行就够拿主意，想核对再看「收益」和「来源」。
- **看到「没核到原文」**：意思是这一点没有找到能逐句核对的官方原文，所以没有写结论。别把它当成「没有问题」。
- **个案**：这本书只写通用口径。自己的申请能不能批、该交多少税，问入管、税务署、年金事务所、役所，或者行政书士、税理士、律师。
- **想让 AI 帮你查**：[skills/zainichi-decision-guide](skills/zainichi-decision-guide/SKILL.md) 是配套的 skill，先查条目再答，注明出自第几节第几条，查不到就说查不到。

每条建议长这样：

```markdown
### 2. 搬家后 14 天内去新住处的市区町村役所办迁入，带上在留卡
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=中 口径=自由 -->
- 成本：不花钱。去一趟役所，带在留卡。
- 说人话：搬家后 14 天内，要带着在留卡去新住处的役所登记。……不报最高罚 20 万日元。搬走后 90 天还不报，在留资格可以被取消。
- 收益：入管法第 19 条的 9 第 1 项要求中长期在留者从搬到新住处那天起「十四日以内」……
- 证据等级：A
- 来源：出入国管理及び難民認定法 第十九条の九…… e-Gov 法令検索 <https://laws.e-gov.go.jp/law/326CO0000000319>
- 备注：刚入境的人是从定下住处那天起 14 天内（第 19 条的 7）。……
```

## 四种资源

和原书一样，一条建议换回的东西分四种，分开算，不互相折算：

- **寿命**：少死于本来可以避免的事。这本书里很少，只有父母手术那一条。
- **时间与精力**：少跑冤枉路，少等。
- **金钱**：该拿的拿到，不该交的不交，别被罚。
- **人身自由**：不因为漏了一个届出、晚交了一次申请，丢掉在留资格或者被处罚。

## 证据分级

| 等级 | 含义 |
| --- | --- |
| A | 有具体数字，或者引到了法条、官方文件的原文 |
| B | 有依据但难量化，或者只有单一来源 |
| C | 作者经验或通行说法，没有可核的原文 |

全书 93 条目前都是 A 级，来源栏共 172 处链接。这不是说这本书特别可靠，而是因为目前只写了能引到原文的事；礼金、更新料、保证公司现在也是按判决文、告示和国土交通省的调查写的，被拒租的救济还没写。

A 级只说明「这句话在原文里有」。法律写着你有权要，不等于你一提就能拿到：多数时候得自己先提出，提了不给再找行政机关，再不行才是调停或诉讼。这几步各要多久、花多少钱，本书大多没有核。

**时效**：金额和期限后面都写了适用的日期或年度。全书截至 2026-10-06。日本和中国的制度都在改，用之前回来源栏的原页看一眼。

## 性价比档

每条另标了三项成本（钱、时间、毅力）、收益量级（大、中、小）和口径。检索页按原书的办法合出一个档：好处大且三项成本全是零，是极高；好处大、成本不高，或者好处中等、成本为零，是高；其余是一般。

全书 93 条中极高 18 条、高 34 条、一般 41 条。这一档是作者的判断，不是证据。「一般」不等于不该做。
