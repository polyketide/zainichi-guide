# 在日华人版 高性价比人生指南（试点）

仿照《高性价比人生指南》的写法，给在日本生活的中国籍读者用。目前是自用的私有稿，写了前 5 节。**不要公开。**

## 出处与许可

- 体例、证据分级、条目格式和排序办法来自《高性价比人生指南》，作者 eternity4719，<https://github.com/eternity4719/HowToLiveBetter>，CC BY 4.0（<https://creativecommons.org/licenses/by/4.0/>）。
- 本仓库的条目是按日本法令和官方文件新写的，不是原书的翻译，内容与原书不同。参照的原书版本是 commit `a4e920f`（2026-10-05）。
- 原书的精读摘要在 `../career/00-career-plan/参考_HowToLiveBetter_精读摘要_2026-10-05.md`。

## 沿用原书的规矩

- 每条回答两件事：花掉什么（钱、时间、毅力），换回什么。四种口径分开算，不互相折算：寿命、时间与精力、金钱、人身自由。
- 证据等级：A 有具体数字或引到法条和官方文件原文；B 有依据但难量化；C 作者经验。
- 来源只引法令原文和官方机构页面，不引二手转述。原文里找不到的数字不写，写「没核到原文」。
- 每条格式：标题（动词开头）、成本标签注释、成本、说人话、收益、证据等级、来源、备注。
- 每节内按性价比从高到低排。

## 日本版多出来的规矩

- **每个金额和期限都写适用日期。** 官网的现行页只回答今天的规则。已公布还没施行的改定，要去入管的通知页查。
- **条文引日文原文，后面跟白话。** 条号放在收益栏和来源栏。
- **每节有一份核实记录**（`docs/核实记录/`）：取了哪些原文、哪天取的、MD5、每条对应哪一条法条、哪些没核到。
- **取原文的办法**：法令走 e-Gov 法令 API，一次取整部法。入管官网在主循环里串行取，每次间隔 2 秒，不并发。
- 金额用日元，不加千分位逗号。

## 目录结构

- `book/` 正文，一节一个文件。
- `docs/核实记录/` 每节的来源核实记录。
- `_sources/` 取回的法令和官方页面原件，核对用。
- `_tools/` 三个小脚本：`art.py` 按条号从 e-Gov 的 XML 里抽条文，`h2t.py` 把日本官网页面转成文本，`c2t.py` 把中国政府网站页面转成文本。
